# HCV missing-data reconstruction and prediction — research project

Study: **Comparative Evaluation of Hybrid MICE–Median Missing-Value Reconstruction and Downstream Hepatitis C Prediction Using Machine Learning**

Authors: Farzana Mehedi Moly, **Md. Razu Ahmed**, Md. Soriful Islam, Jannatul Mauya, and Md. Shamim Reza.

This folder contains the figure assets for the detailed case study on `projects.html#hcv-mice-median-project`.

## Upload optimized author figures

1. Download and extract `HCV_Portfolio_Figures.zip` from the ChatGPT conversation.
2. On GitHub, open `assets/academic/projects/hcv-mice-median/`.
3. Upload the two WebP files and `figure-manifest.json` directly here, **without creating a nested folder**.
4. Keep the filenames unchanged:

- `fig01-hcv-evaluation-workflow.webp` — full predictive / reconstruction study design; featured only once.
- `fig02-hybrid-mice-median-reconstruction.webp` — artificial masking and 50:50 MICE–Median reconstruction protocol; featured only once.

The WebP files are compressed display derivatives of the author's original full-resolution PNGs. No figures or reported results were invented.

This study treats **downstream prediction** (complete-case vs. MICE-based imputation) separately from **artificial-missingness reconstruction** (MICE, median, sampling, and Hybrid MICE–Median). Do not describe hybrid imputation as having improved downstream prediction.

The underlying UCI HCV dataset is https://archive.ics.uci.edu/dataset/571/hcv%2Bdata (dataset DOI `10.24432/C5D612`). That DOI is **not** an article DOI for this HCV study.

The article venue, submission/acceptance status, and manuscript DOI were not supplied.
