**Upload target:** `assets/academic/projects/hcv-mice-median/` in `beingrazuahmed/beingrazuahmed.github.io` on `main`.

1. Extract this ZIP.
2. Upload `fig01-hcv-evaluation-workflow.webp`, `fig02-hybrid-mice-median-reconstruction.webp`, and `figure-manifest.json` **directly into the target GitHub folder**.
3. Commit. Do not upload the ZIP itself, add a second nested folder, or rename the files.

The WebP images are optimized derivatives of the two author-provided original PNG figures; original full-resolution PNGs remain in `HCV Figs.zip`. The website does not claim journal publication or repository code availability.
