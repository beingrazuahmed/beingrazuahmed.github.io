# Md. Razu Ahmed — Academic & Research Portfolio

Production repository for the public academic portfolio of Md. Razu Ahmed.

## Design goals

- Readable, responsive academic portfolio for desktop, tablet and mobile
- Sky-blue/white light theme and deep-navy dark theme
- Structured public research data with filters and search
- Evidence-grounded, privacy-aware Ask Razu AI
- Public scholarly profiles, publications, datasets, peer-review service, academic journey and research network
- No confidential manuscript content in the public repository

## Main files

- `index.html` — portfolio homepage
- `styles.css` — responsive design system
- `data.js` — canonical public portfolio data
- `script.js` — dynamic rendering, filtering, dark mode and Ask Razu AI
- `cv.html` — print-friendly public CV view

## Privacy

The public repository intentionally excludes confidential manuscripts, private reviewer material, editorial correspondence, manuscript IDs, private contact information and any non-public collaborator information.
